# 시영과민수 공식 사이트

1. **문구·가격 수정** — `site-config.js`를 메모장으로 열어 따옴표 안의 글자와 숫자만 고치고 저장하면 바로 반영됩니다.
2. **화면에서 수정** — `index.html`을 열고 주소 끝에 `?edit=1`을 붙인 뒤 글자를 눌러 고치고, [site-config.js 내려받기]를 눌러 이 폴더의 같은 파일에 덮어쓰세요.
3. **무료 배포** — https://vercel.com/new 에서 이 폴더를 통째로 끌어다 놓으면 끝 (GitHub Pages·Cloudflare Pages도 동일).
4. **사진 추가** — `assets/img/`에 사진을 넣고 `site-config.js`의 `image` 경로만 바꿔 주세요.
5. **유튜브 교체** — `url` 칸에 유튜브 주소를 붙여넣으면 썸네일과 재생이 자동으로 연결됩니다.
